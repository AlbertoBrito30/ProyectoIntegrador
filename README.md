# Let's go vet

Aplicación web para la gestión interna de una clínica veterinaria,
desarrollada con PHP, HTML, CSS y MySQL/MariaDB.

El sistema permite administrar servicios, productos, pacientes y
facturación, mediante operaciones CRUD, autenticación de usuarios
y manejo de sesiones.

- MySQL/MariaDB
- Apache (XAMPP)

## Instalación

1. Instalar XAMPP e iniciar Apache y MySQL.
2. Copiar el proyecto dentro de `htdocs`.
3. Importar `config/lets_go_vet.sql` desde phpMyAdmin.
4. Revisar la configuración de conexión en `config/conectionDB.php`.
5. Abrir el proyecto desde el navegador.
